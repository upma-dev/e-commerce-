# Twee Haven | Cozy Handmade Crochet & Accessories

A boutique e-commerce application for handmade crochet bags, accessories, and cozy custom creations.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
